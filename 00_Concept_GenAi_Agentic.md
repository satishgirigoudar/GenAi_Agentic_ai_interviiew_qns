# GenAI / Agentic AI — Concept Map — Topics to Master

## 1. Generative AI Concepts (Core GenAI)

### A. Foundation Models & LLMs
- Transformer Architecture
- Attention Mechanism / Self-Attention
- Positional Encoding
- Encoder vs Decoder Models
- Tokenization
- Embeddings
- Context Window
- Model Parameters
- Training vs Inference
- Open Source Models vs Closed Models (GPT, Llama, Gemini, Mistral)

### B. Prompt Engineering
- Zero-Shot / One-Shot / Few-Shot Prompting
- Chain of Thought (CoT)
- Self Consistency
- Role Prompting
- Structured Prompting / Output Formatting
- Prompt Templates
- Prompt Evaluation

### C. Embeddings
- Text Embeddings
- Similarity Search / Cosine Similarity
- Semantic Search
- Embedding Models
- Dense Retrieval

### D. Vector Databases
- Vector Storage, Indexing, ANN Search, Metadata Filtering
- Popular DBs: Pinecone, Weaviate, Qdrant, Chroma, Milvus

### E. RAG (Retrieval-Augmented Generation)
- Data Loading → Chunking → Embedding Generation → Vector Storage → Retrieval → Re-ranking → Context Injection → Response Generation → RAG Evaluation
- Advanced: Hybrid Search, Parent-Child Retrieval, Multi-Vector Retrieval, Graph RAG, Corrective RAG (CRAG), Adaptive RAG

### F. Fine-Tuning & Model Customization
- Fine-Tuning, Instruction Tuning
- LoRA, QLoRA, PEFT
- Supervised Fine-Tuning (SFT)
- RLHF, DPO

### G. LLM Evaluation
- Hallucination Detection, Groundedness, Faithfulness, Relevance
- Latency Metrics, Cost Analysis, Benchmarking, A/B Testing

### H. Multimodal AI
- Text-to-Image, Image-to-Text, OCR
- Vision Language Models
- Speech-to-Text, Text-to-Speech, Video Understanding
- Examples: GPT Vision, Gemini Vision, Stable Diffusion

### I. LLM Application Development
- Frameworks: LangChain, LlamaIndex, Haystack
- Use cases: Chatbots, Document Q&A, Knowledge Assistants, Enterprise Search, AI Copilots, Content Generation Systems

### J. Deployment & Production GenAI
- Model Serving, API Development (FastAPI)
- Docker, Kubernetes
- Monitoring, Logging, Scaling, Caching
- Cost Optimization, Security

## 2. Agentic AI Concepts

### A. AI Agents
- Agent Architecture, Agent Loop
- Planning, Reasoning, Reflection, Self-Correction

### B. Tool Calling
- Function Calling, API Calling
- Tool Selection, Tool Routing, Structured Outputs

### C. Multi-Agent Systems
- Agent Communication, Agent Collaboration
- Supervisor Agent, Worker Agents, Agent Orchestration

### D. Agent Frameworks
- AutoGen, CrewAI, LangGraph, Semantic Kernel

### E. Agent Memory
- Short-Term Memory, Long-Term Memory
- Episodic Memory, Semantic Memory

### F. Agent Planning
- ReAct Pattern, Plan-and-Execute
- Tree of Thoughts, Graph of Thoughts, Reflection Loops
